## Concept

Every morning, before the market opens, there's a window where serious investors review the previous day. The EGX Daily Snapshot is built for that window: a clean, structured summary of what happened, without noise.

## What it generates

Each report includes:
- **Top movers** — 5 biggest gainers and losers by price change, with volume context
- **Volume anomalies** — stocks where volume was more than 2 standard deviations above the 20-day average
- **Sector summary** — sector-level performance table
- **One highlighted observation** — the most interesting thing in the data that day, generated by a simple rule-based system (e.g., "CIB traded 3.2x normal volume and closed at a 52-week high")

## How it works

A Python cron job runs at 5:30 AM Cairo time, pulls the previous day's data from the EFG API, processes it, and outputs a structured Markdown report. The report is:
1. Posted to a web page (updated daily)
2. Sent to a Telegram channel (400+ subscribers)
3. Available as JSON via a simple API endpoint

The whole thing runs on a EGP 25/month VPS.

## Status

Live and running daily since March 2026. Zero downtime days to date. The EFG API has been reliable; the occasional issue has been with the cron scheduler, not the data.
